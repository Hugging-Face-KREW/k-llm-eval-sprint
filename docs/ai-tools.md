# AI 도구 사용 원칙

AI 도구는 써도 됩니다. 에러 해석, 코드 이해, 번역, 초안 작성에 적극적으로 쓰세요.

지켜 주세요.

- 올리는 코드와 글은 내가 설명할 수 있어야 합니다. 설명하지 못하는 코드는 올리지 않습니다.
- PR 설명과 리뷰 답변은 직접 씁니다. 번역기로 옮긴 뒤 다듬는 건 괜찮습니다.
- 메인테이너에게 AI 답변을 그대로 붙여 넣지 않습니다.

Lighteval은 사실상 한 명의 리뷰어가 PR을 검토하고 있습니다. 네 팀의 PR이 비슷한 시기에 올라가는 만큼, 한 팀의 PR에서 받은 인상이 다른 팀의 PR 리뷰에도 영향을 줄 수 있습니다.
