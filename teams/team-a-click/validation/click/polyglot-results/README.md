## 구현 검증과 실행 증빙

| 모델 | Lighteval ↔ 하네스 예측 일치 | 최대 후보 점수 차이 | 사전 고정 허용오차 | 판정 |
| --- | ---: | ---: | ---: | --- |
| 1.3B | 1995 / 1,995 | 0.000188827515 | 0.000205993652 | PASS |
| 12.8B | 1995 / 1,995 | 0.000129699707 | 0.000202178955 | PASS |

두 모델 모두 55문항의 세 경로 점수로 허용오차를 정하고 별도 69문항에서 검증한 뒤 전체 평가에 적용했습니다.
독립 forward 검산은 파일럿 124문항에서 수행했고, 전체 1,995문항은 두 native 도구로 비교했습니다.
단위 테스트 120개, GPU 검증용 모델, 원본·입력·실제 forward 토큰 검사도 통과했습니다.
문항 누락·잘림·예측 불일치·점수 허용오차 초과는 모두 0건입니다.

실행은 `tailab2` GPU 3번 A100X 하나, `tailab:0.0.1` 전용 컨테이너에서 FP32/eager/TF32 off로 수행했습니다.
호스트 전역환경은 변경하지 않았습니다. 전체 실행은 2026-11-11 14:13–17:28 KST, 종료 코드는 0입니다.
원본 산출물 34파일을 로컬 ignored 폴더로 회수해 해시를 대조했고, 회수본으로 두 전체 보고서를 재생성해 PASS를 확인했습니다.
이는 native Python API 검증이며 두 CLI 전체 실행 검증은 아닙니다. M02의 실제 데이터 최대 길이는 1,896토큰으로 한도 2,048 이내이며,
초과 차단은 단위 테스트로 확인했습니다. 2,048 경계의 합성 문항을 GPU로 평가한 결과를 뜻하지 않습니다.

## 논문 비교와 다음 확인

[CLIcK 논문 Table 5](https://arxiv.org/html/2403.06412v2#S4.T5)의 분야별 수치와 이번 결과의 차이는
[1.3B 보고서](1.3b/report.md)와 [12.8B 보고서](12.8b/report.md)에 정리했습니다.
논문은 지시문 3종과 보기 순환을 사용하며, 이번 평가는 0-shot·단일 지시문·원본 순서·후보 전체 로그 확률 합을 사용합니다.
논문의 Average와 이번 micro/macro를 같은 산식으로 가정하지 않습니다.

현재 Polyglot 비교·결과 정리는 완료했습니다. 다음 단계는 팀원이 입력 정렬과 결과를 교차 검토하고,
이 증빙을 제출 자료에 반영하는 일입니다. 12.8B 점수 차이의 원인을 확인하려면 지시문·보기 순서·채점 조건을
하나씩 바꾼 별도 실험이 필요합니다. Qwen·Kanana 평가, 전체 CLI 검증, PR 제출은 이번 실행에 포함하지 않았습니다.
